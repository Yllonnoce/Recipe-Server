Backup server

On the main server: enter the backup server's address below and this library is sent to it on a schedule; the backup server merges it in, so if this machine ever dies the backup has every recipe, PDF and picture. The backup server needs nothing configured; it just has to be a Recipe Library that is switched on.

The other way round: make this machine copy from a main server on its own

Useful when the backup machine can reach the main server but not the reverse. Leave it empty otherwise.
