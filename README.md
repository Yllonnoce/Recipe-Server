# Recipe Library

A self-hosted recipe library for the family. Print a recipe page from any device to the
"Recipe Library" network printer, paste a URL, or drop a PDF into the inbox folder. The
server keeps the PDF as the archive copy, pulls out the ingredients and steps, and lets
everyone on the home Wi-Fi browse, search, cook, plan meals and build a shopping list.

See `docs/install.md` to get it running.
